# API Endpoints - Civitas

## Usuarios

GET /api/usuarios\
Envia: nada (opcional: ?pageNumber=&pageSize=)\
Retorna: { code, data: UsuarioDTO\[\], message }

GET /api/usuarios/cpf\
Envia: ?cpf=string\
Retorna: { code, data: UsuarioDTO\[\] \| null, message }

GET /api/usuarios/{id}\
Envia: id na rota\
Retorna: { code, data: UsuarioDTO \| null, message }

POST /api/usuarios\
Envia (body): { cpf, nome, rg, logradouro, numero, cidade, estado, cep,
bairro, email, senha, matricula, situacao, tipoUsuario }\
Retorna: { code, data: UsuarioDTO, message }

PUT /api/usuarios/{id}\
Envia: id na rota + body igual POST\
Retorna: { code, data: UsuarioDTO, message }

DELETE /api/usuarios/{id}\
Envia: id na rota\
Retorna: { code, data: null, message }

PATCH /api/usuarios/situacao/{id}\
Envia: id na rota\
Retorna: { code, data: { id, situacao }, message }
